================================================================================
MASTER PROMPT & PROJECT SPECIFICATION (CURRENT STATE)
AI Presentation & Q&A Rehearsal Coach (SpeakQuest)
================================================================================

1. บริบทและเป้าหมายของโปรเจกต์ (Project Overview)
--------------------------------------------------------------------------------
- ชื่อโปรเจกต์: AI Presentation & Q&A Rehearsal Coach (SpeakQuest)
- เป้าหมาย: พัฒนา Web Application เพื่อเป็นพื้นที่ซ้อมพรีเซนต์งานและจำลองการตอบคำถาม
  (Safe Space Rehearsal) ช่วยให้นิสิตนักศึกษาพัฒนาทักษะการสื่อสาร ความมั่นใจ
  การบริหารเวลา และการตอบคำถาม Q&A ก่อนลงสนามจริง (สอบโปรเจกต์, พรีเซนต์ทีสิส, สัมภาษณ์งาน)

2. สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)
--------------------------------------------------------------------------------
[Backend - NestJS (TypeScript) @ Port `process.env.PORT ?? 3000`]
- Framework: NestJS + Socket.IO (`RemoteGateway` สำหรับรีโมทมือถือผ่าน QR Code)
- AI SDK: `@google/genai` (โหลด `GEMINI_API_KEY` จาก `backend/.env` ด้วย `process.loadEnvFile()`)
  - JSON / Text Tasks: ใช้ค่าเริ่มต้นของ SDK + fallback models (`GEMINI_MODEL` -> `gemini-3.1-flash-lite` -> `gemini-2.5-flash-lite` -> `gemini-2.5-flash`)
  - Gemini TTS (`synthesizeSpeech`): ใช้ `apiVersion: 'v1beta'` และแปลง PCM 24kHz เป็น WAV Data URL (`pcmToWavDataUrl`) พร้อม in-memory cache และ fallback อัตโนมัติหากโมเดลไม่รองรับ `speechConfig`

[Frontend - React + Vite]
- UI & Styling: React + Tailwind CSS (ห้ามใส่ emoji ในข้อความ UI ทุกจุด, ใช้ภาษาไทยที่เข้าใจง่าย)
- Slide Viewer: `pdfjs-dist` (เรนเดอร์ไฟล์ PDF เป็นภาพ และดึงข้อความแต่ละสไลด์)
- Speech-to-Text: Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`) ถอดเสียงไทย/อังกฤษแบบ real-time
- Eye Contact Tracking: MediaPipe `@mediapipe/tasks-vision` (`FaceLandmarker`) วิเคราะห์การมองกล้อง
- Recording: MediaRecorder API บันทึกเสียงพูด + บันทึกวิดีโอกล้องหน้าแบบ Local (ดาวน์โหลดเป็น WebM)
- Mobile Remote: `qrcode.react` + `socket.io-client` เชื่อมต่อรีโมทเปลี่ยนสไลด์จากมือถือ

3. ลำดับขั้นตอนการทำงานในแอปปัจจุบัน (Current User Journey)
--------------------------------------------------------------------------------
Step 1: [ModeStep] เลือกกลุ่มผู้ฟังและตั้งค่าเริ่มต้น
- เลือกกลุ่มผู้ฟัง (Audience): `general` (คนทั่วไป), `teacher` (อาจารย์/กรรมการ), `executive` (ผู้บริหาร/นักลงทุน)
- ตั้งค่าห้องซ้อมผ่าน `RoomSetupModal` (เป้าเวลาซ้อมรวม, รูปแบบการซ้อมทีละหน้า/ต่อเนื่อง, กล้อง, คำถามแทรก, เสียง Gemini TTS)

Step 2: [UploadStep] อัปโหลดสไลด์
- รองรับไฟล์ PDF และไฟล์รูปภาพ พร้อมดูตัวอย่างสไลด์และปรับตั้งค่าห้องซ้อมก่อนเริ่ม

Step 3: [RehearsalStep] ซ้อมพรีเซนต์
- รองรับ 2 โหมด:
  1) ซ้อมทีละสไลด์ (Slide-by-Slide): อัดเสียง/ตรวจ AI ทีละหน้า และซ่อมเฉพาะหน้าได้
  2) ซ้อมต่อเนื่องแบบไม่หยุด (Continuous Dress Rehearsal): พรีเซนต์รวดเดียวตั้งแต่ต้นจนจบแล้วสรุปผลรวม
- Target Timer: นับเวลาซ้อมรวมเทียบกับเป้าหมายเวลาที่ตั้งไว้
- Real-time Metrics: ความเร็วการพูด (WPM), คำฟุ่มเฟือย (Filler Words), ช่วงเงียบ (Dead Air), เปอร์เซ็นต์การสบตากล้อง (Eye Contact %)
- Floating Camera & Local Video Recording: กล้องหน้าลอยปรับขนาดได้ (ลากมุมหรือเลือก S / M / L) พร้อมบันทึกวิดีโอเก็บไว้ดูย้อนหลังหรือดาวน์โหลด
- Stage Mode & Mobile Remote: เปิดโหมดเต็มจอและสแกน QR Code เพื่อใช้มือถือเป็นรีโมทกดเลื่อนสไลด์
- AI Slide Check (`POST /api/gemini/check-slide`): ส่งภาพ/เนื้อหาสไลด์ + บทพูดให้ AI ทำ Listener Summary, ตรวจความครบถ้วน และแนะนำจุดปรับปรุง
- คำถามแทรกระหว่างพรีเซนต์ (`InterruptModal` + `POST /api/gemini/qa/interrupt`): สุ่มถามแทรก (~20% ต่อสไลด์ที่ยังไม่เคยถาม) และอ่านคำถามออกเสียง

Step 4: [QaStep] จำลองถาม-ตอบ Q&A
- AI วิเคราะห์สไลด์และบทพูดทั้งหมดเพื่อสร้างคำถามเจาะจุดโหว่ (`POST /api/gemini/qa/generate`)
- ผู้ใช้กดอัดเสียงตอบคำถามสด และให้ AI ประเมินคำตอบ (`POST /api/gemini/qa/evaluate`)
- Toggle เสียง Gemini TTS (`POST /api/gemini/tts`):
  - ค่าเริ่มต้นเป็น "ปิด" (ใช้เสียงเบราว์เซอร์ `speechSynthesis` เพื่อความเร็วและประหยัดโควต้าเวลาเทส)
  - เมื่อกด "เปิด" จะเรียก Gemini TTS และ cache เสียงไว้สำหรับปุ่ม "ฟังซ้ำ" (หากเรียกไม่สำเร็จจะสลับกลับเสียงเบราว์เซอร์อัตโนมัติ)

Step 5: [SummaryStep] แดชบอร์ดสรุปผล
- สรุปเวลาที่ใช้, คะแนนความพร้อม, สถิติการพูดรายสไลด์, ผลประเมิน Q&A, วิดีโอที่บันทึกไว้ และบทวิเคราะห์ภาพรวมจาก AI (`POST /api/gemini/analyze-summary`)

4. โครงสร้างไฟล์สำคัญ (Key Files)
--------------------------------------------------------------------------------
[Backend - `backend/src/`]
- `main.ts` - Bootstrap NestJS + CORS + JSON body limit
- `app.module.ts` - Root module (`GeminiModule`, `RemoteModule`)
- `gemini/gemini.controller.ts` - REST endpoints (`/api/gemini/*`)
- `gemini/gemini.service.ts` - Logic เรียก Gemini API, JSON fallback, และ TTS (`v1beta` + WAV conversion)
- `remote/remote.gateway.ts` - Socket.IO gateway สำหรับ QR Mobile Remote

[Frontend - `frontend/src/`]
- `App.jsx` - Main state & 5-step flow (`mode` -> `upload` -> `rehearsal` -> `qa` -> `summary`) + route `/remote/:roomId`
- `components/Header.jsx` - แถบนำทางด้านบนและตัวบอกขั้นตอน
- `components/ModeStep.jsx` - หน้าเลือกกลุ่มผู้ฟังและเข้าตั้งค่าห้องซ้อม
- `components/RoomSetupModal.jsx` - หน้าต่างตั้งค่าเวลา, โหมดซ้อม, กล้อง, คำถามแทรก, เสียง Gemini
- `components/UploadStep.jsx` - อัปโหลดและแปลงสไลด์ PDF/รูปภาพ
- `components/RehearsalStep.jsx` - หน้าซ้อมพรีเซนต์หลัก, จับเวลา, กล้อง, รีโมท, คำถามแทรก
- `components/FloatingCamera.jsx` - หน้าต่างกล้องลอยปรับขนาดได้ (ลากมุม / S, M, L)
- `components/SlideViewer.jsx` - แสดงสไลด์ปัจจุบัน
- `components/InterruptModal.jsx` - หน้าต่างคำถามแทรกระหว่างพรีเซนต์
- `components/QaStep.jsx` - หน้าถาม-ตอบ Q&A ท้ายการซ้อม
- `components/SummaryStep.jsx` - หน้าสรุปผลคะแนนและดาวน์โหลดวิดีโอ
- `components/RemotePage.jsx` - หน้าจอมือถือสำหรับควบคุมสไลด์ผ่าน QR Code
- `lib/api.js` - Client เรียก Backend REST API (`/api/gemini/*`)
- `lib/metrics.js` - คำนวณ WPM, filler words และสถิติการพูด
- `lib/slides.js` - แปลงและดึงข้อความจากไฟล์สไลด์ PDF/รูปภาพ
- `lib/socket.js` - Socket.IO client
- `lib/speech.js` - จัดการเสียงพูดคำถาม (Gemini TTS + cache + fallback `speakThai`)
- `lib/useAudioRecorder.js` - Hook อัดเสียงและจัดการ blob เสียง
- `lib/useSpeechRecognition.js` - Hook Web Speech API ถอดเสียงแบบ real-time
- `lib/useVideoRecorder.js` - Hook อัดวิดีโอกล้องหน้าแบบ Local (WebM)
- `lib/useFaceLandmarker.js` - Hook MediaPipe FaceLandmarker ตรวจการสบตากล้อง

5. กติกาการพัฒนาและคำสั่งรันโปรเจกต์ (Conventions & Commands)
--------------------------------------------------------------------------------
[Conventions]
- ห้ามใช้ emoji ในข้อความ UI ทุกจุดเด็ดขาด
- ข้อความ UI ใช้ภาษาไทยที่เป็นมิตร กระชับ อ่านง่ายสำหรับผู้เริ่มต้น
- ห้าม commit ไฟล์ `backend/.env` (เก็บ `GEMINI_API_KEY` ไว้ในเครื่องเท่านั้น)

[Run Development Servers]
- Backend: `npm --prefix backend run start:dev` (Port `process.env.PORT ?? 3000`)
- Frontend: `npm --prefix frontend run dev` (Vite proxy `/api` และ `/socket.io` ไปยัง backend)
- Build Check:
  - `npm --prefix backend run build`
  - `npm --prefix frontend run build`
